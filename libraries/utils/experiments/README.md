# experiments

This folder contains helper functions used in experimental setups
and simulation workflows.

The focus is on supporting validation and benchmarking,
not on implementing algorithms.

## Structure

```
experiments/
└── simulations.py   # Utilities for generating and running simulations
```

## Module usage

Modules in this folder are used by experiment and validation scripts.
They provide reusable building blocks for repeated runs
and controlled experimental setups.
