# _img

This folder contains figures and plots generated by simulation,
benchmark, and validation scripts.

The contents are derived artifacts and are not used as inputs
to any algorithmic components.

## Structure

```
_img/
├── benchmarks/   # Figures from performance benchmarks
└── validation/   # Figures from validation experiments
```

Subfolders are typically organized by problem type and experiment category.

## Module usage

Images in this folder are produced automatically by simulation scripts
and are used for analysis, reporting, and documentation.
