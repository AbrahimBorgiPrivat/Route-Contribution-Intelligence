New York Bus Route Demo

How to use this page

Use this page to get a quick overview before opening a scenario or a route. Filter by Label, Profile and Analysis period, compare KPI cards, and open the scenarios you want to inspect.

Label

Label describes the route setup. In this demo the labels are simple bus route groups such as all routes, day buses, evening buses, morning, night and rush hour.

Profile

Profile is the operating profile used to score the route. It lets you compare scenarios under different assumptions.

Analysis period

Analysis period shows the time window used for evaluation. It helps check whether a scenario stays stable across periods.
