What is this page for?

This page shows one selected scenario in route detail.

Overview Scenario view Route view

Key terms

These are the main terms used here.

Label Label tells you which route setup you are looking at.
Profile Profile is the operating profile used in the score.
Analysis period Analysis period shows the time window used for the scenario.
Change cards Change cards summarize the move from original to optimized.
KPI cards KPI cards show the main numbers for Type 1 and Type 2.
Route overview The route overview breaks the scenario down by route.

How to use it

  • Check the metadata line at the top.
  • Read the change cards first.
  • Use the KPI cards to confirm the direction.
  • Move to the route overview to find the drivers.

What the route overview is for

Rows Each row is one route.
Type 1 and Type 2 The two groups let you compare the same route across model types.
Transport mode Shows the mode used for the route and acts as a filter.
Sign. outliers Shows how many significant outliers the route has.
Open route The button opens the route detail page.

When does a scenario look strong?

  • When the change cards point in the right direction.
  • When the KPI cards confirm the same picture.
  • When the route overview shows the gain is not driven by one route only.
  • When the map also looks reasonable.
