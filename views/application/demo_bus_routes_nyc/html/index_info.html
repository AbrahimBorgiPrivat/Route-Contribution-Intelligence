What is this page for?

This is the starting point. Use the filters to narrow the scenarios, compare them, and open the one you want to inspect.

Overview Scenario view Route view

Key terms

These are the main terms used on the overview page.

Label Label describes the route setup, such as a day, evening, morning or rush hour group.
Profile Profile is the operating profile used in the score.
Analysis period Analysis period shows the time window used for evaluation.
Type 1 and Type 2 Type 1 keeps the order fixed. Type 2 may reorder the route.
Original and optimized Original is the baseline. Optimized is the best solution found.
Significant outliers These mark the most important problem spots on the route.

How to use it

  • Start with Label, Profile and Analysis period.
  • Use the overview to compare revenue, cost and outliers.
  • Open the most interesting scenario when you want to go deeper.
  • Use the expandable blocks for period and KPI details.

What the overview shows

Rows Each row is one scenario for a specific Profile and Label.
Column groups Type 1 and Type 2 are shown side by side.
DB, revenue and costs Both original and optimized values are shown.
Open scenario The button opens the selected scenario.
Week buttons Use the arrows to switch between analysis periods.

When is a scenario worth looking at?

  • When optimized DB rises without costs eating the gain.
  • When Type 2 consistently beats Type 1.
  • When the scenario stays stable across periods.
  • When the number of significant outliers is low.
Use the overview to choose a direction, then use the scenario and route pages to explain why.
