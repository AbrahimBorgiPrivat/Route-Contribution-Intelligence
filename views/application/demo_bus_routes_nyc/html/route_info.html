Info: Route

Documentation for html/route.html

What is this page for?

This is the most detailed view. It shows one route and compares the original and optimized versions.

Overview Scenario view Route view

Key terms

These are the main terms used on the route page.

Type 1 Type 1 keeps the route order fixed.
Type 2 Type 2 may reorder the route to find a better solution.
Original and optimized Original is the baseline. Optimized is the best solution found.
Outlier An outlier is a route segment that looks unusually costly.
Length to next Shows the distance or time to the next stop.
APR x length A simple cost measure for the segment to the next stop.

How to use it

  • Start with the KPI tables.
  • Read the outlier table next.
  • Use the map to check the geography.
  • Finish with the stop tables.

What to look for

Better margin A higher margin is usually a good sign.
Fewer outliers Fewer problem spots usually means improvement.
Cleaner route The map should still look sensible.
Stop tables These show the exact order and stop-level changes.

How to read the stop tables

Route no. The position in the shown order.
Original no. The position in the original order.
Address The stop address.
Revenue The value contributed by the stop.
Length to next Distance or time to the next stop.
APR x length The cost of the segment to the next stop.
Significant outlier Marks whether the stop is a clear issue.
